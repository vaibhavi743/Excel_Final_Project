# Data Intelligence Dashboard – Final Project

## Project Overview

The **Data Intelligence Dashboard** is an Excel-based data analysis project designed to transform customer transaction data into meaningful business insights. 
It uses Excel formulas, summary tables, charts, and a dashboard to analyze sales performance, product demand, regional revenue, and customer purchasing behavior.

## Project Objectives

* Analyze customer transactions and total revenue.
* Identify popular products and high-value customers.
* Compare revenue across regions and product categories.
* Analyze monthly revenue trends.
* Present key metrics using charts and KPI cards.
* Communicate findings through a dashboard and final report.

## Dataset Description

The dataset contains **250 transaction records** with the following fields:

* Transaction ID
* Date
* Customer ID
* Customer Name
* Product ID
* Product Name
* Category
* Quantity
* Unit Price
* Payment Method
* Region
* Customer Segment
* Customer Since
* Total Amount

## Workbook Structure

### 1. Raw Data

Contains the original transaction records in a structured Excel table. 
This sheet is used as the source for calculations and analysis.

### 2. Analysis

Uses Excel formulas and functions to analyze the data, including:

* `TODAY()`, `NOW()`, `DATEDIF()`, and `EOMONTH()` for date calculations
* `SUMIF()` and `SUMIFS()` for sales and customer summaries
* Customer purchase totals and classification
* Product purchase frequency
* Customer initials and abbreviations
* Conditional formatting to highlight important values

### 3. Visualization Summary

Contains summary tables prepared for creating charts:

* **Product Summary:** Total quantity and revenue by product
* **Region Summary:** Revenue by region
* **Category Summary:** Revenue by product category
* **Monthly Trend:** Revenue by month
* **Top Customers:** Customers ranked by purchase amount

### 4. Visualizations

Contains charts that present summarized data, including:

* Bar charts for product and regional comparisons
* Line chart for monthly revenue trends
* Pie chart for category revenue share
* Customer comparison chart

### 5. Dashboard

Displays key performance indicators and charts in one place for a quick overview of business performance.

### 6. Final Report

Summarizes the main findings and provides business recommendations based on the analysis.

## Key Insights

* **Total Revenue:** $229,192.47
* **Total Transactions:** 250
* **Total Units Purchased:** 753
* **Unique Customers:** 50
* **Top Revenue Region:** East – $59,288.39
* **Most Purchased Product by Quantity:** Bookshelf – 102 units
* **Highest-Value Customer:** Mark Carter (CUST025) – $15,659.65 in purchases

## Business Recommendations

* Monitor regional performance and investigate the strong revenue contribution from the East region.
* Maintain sufficient inventory of frequently purchased products such as Bookshelf.
* Develop customer-retention strategies for high-value customers.
* Review monthly revenue trends to support sales planning.
* Use dashboard KPIs and charts for regular business performance monitoring.

## Project Limitations

The dataset does not contain **Profit** or **Discount** columns. Therefore, profit analysis and discount-impact calculations cannot be reliably performed using the available data.

## Conclusion

This project demonstrates how Excel can be used to organize transaction data, perform analysis, summarize results, and communicate insights through visualizations. The dashboard provides an overview of sales, products, regions, and customer purchasing behavior to support data-driven decision-making.
